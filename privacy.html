개인정보처리방침

GGB는 개발자 본인 한 명만 사용하는 개인용 도구입니다.

  • 요청 권한: Gmail 읽기 전용(gmail.readonly), 본인 소유 Google 스프레드시트 쓰기.
  • 사용 목적: 본인 계정의 카드 명세서 메일을 읽어 본인 가계부를 정리하는 것뿐입니다.
  • 보관: 가져온 데이터는 본인 컴퓨터에만 저장되며, 외부 서버로 전송하지 않습니다.
  • 제공: 어떤 데이터도 제3자에게 판매·공유·제공하지 않으며 광고에 사용하지 않습니다.
  • 삭제: Google 계정의 보안 설정에서 언제든 접근 권한을 철회할 수 있고, 로컬 데이터는 본인이 삭제합니다.

Google API에서 받은 정보의 사용은 Limited Use 요건을 포함한 Google API Services User Data Policy를 따릅니다.

Privacy Policy (English)

GGB is a personal tool used only by its developer. It reads the developer's own Gmail (read-only) to organize personal card statements and stores the data only on the developer's own computer. No data is sold, shared, or transferred to third parties or used for advertising. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
